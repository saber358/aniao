本包承载 Aniao Harness 桌面界面。Agent 循环、模型接入、工具执行和会话持久化复用现有 Pi 包。

当前桌面分发版本为 `0.80.25`，内核为官方 Pi `1.4.0`。本版新增使用统计与归档管理，统一设置字级和宽度，修复侧栏拖拽与宽度恢复，并更新 Aniao grok-4.7 地址；提供 Windows x64 与 Linux amd64 `.deb`。发布产物与验收报告保存在 `artifacts/publish-0.80.25-20261028/`。`pi-ai`、`pi-agent-core`、`pi-coding-agent` 与 `pi-tui` 均固定为该内核版本，开发、测试和打包共用同一套发布包；仓库中的 `0.80.6` Pi 源码不再作为桌面入口。课程包 `packages/pi-course` 已按用户要求移除。

侧栏顶部提供品牌、“新会话”主按钮，以及已接通的插件和自动化任务入口。插件页展示当前资源，自动化页管理定时任务与后台任务。工作区按索引保存的顺序展示，打开会话不会把项目或会话移到前面；摘要刷新与重启保持原位置，新建会话放在前面，显式置顶仍有效。所有工作区使用相同的会话行，只有会话显示选中背景，工作区不显示选中背景；字号、字重、行高、缩进、图标和菜单占位保持一致。各工作区统一每批展示 50 个会话，不再显示“查看全部 X 个会话”，展开更多后切换会话不收回列表。显示名称统一为 Aniao Harness，包名、Pi 配置与数据目录沿用原标识。

会话菜单支持所有工作区的重命名、置顶与归档，操作其他工作区不会切换当前会话。主进程按已登记身份查找目标目录，未打开的已保存历史由 SDK 追加名称记录，不创建 Agent 宿主。只有目标会话仍在运行时需要等待后再重命名；置顶与归档可在运行时修改。导航准备期间保留已有画面，目标快照和草稿就绪后才切换，侧栏不因导航整体变灰；列表摘要更新后再刷新项目，并丢弃迟到结果。

左栏拖拽遵循 240–380 px 宽度限制。收起只隐藏并归零面板宽度，保留面板顺序、分隔条和本次窗口内的用户宽度；再次展开后鼠标与键盘方向不变。窗口缩放由主区吸收，设置页隐藏期间缩放也会在返回时恢复左栏宽度。左栏拖拽时原生网页暂时让出鼠标区域，结束后恢复同一网页；窄窗口中右栏会随可用空间收窄，至少保留 320 px 对话区。

设置新增「数据与统计」分组。「使用统计」读取本机真实 SDK 历史，展示累计与峰值 Token、最长聊天时长、连续天数、年度热力图、近 7/30 日趋势和模型占比。「归档管理」支持自动归档策略、搜索排序、项目分组、取消归档和带确认的删除；跳过置顶及运行会话，删除历史送入系统回收站，项目文件保留。数据口径与进程边界见 [设置数据说明](docs/settings-data.md)。

完整设计见 [实施方案](IMPLEMENTATION_PLAN.md)。方案分别覆盖界面、交互、展示、功能，并标明现有接口、缺口、开发顺序和验收条件。

已接入 Nuxt UI 的分栏、聊天、输入区、菜单和弹窗，正文采用 Comark / Shiki，工程面板使用 Monaco 和 xterm.js。接入边界与后续分期见方案第 7 节。

桌面启动时先展示独立的 1320 × 880 无框品牌页，与初始化工作台共用外框尺寸，交接时不再突然放大窗口。终端标记与放大的 Aniao 字标依次淡入，加载条和真实状态集中在字标下方，淡网格向四周渐隐。颜色沿用工作台的深浅主题，系统开启“减少动态效果”后禁用位移与循环动画。启动页不加载 Vue 或 SDK，不显示虚假百分比。浏览器预览按同一尺寸展示，视口不足时缩小到可用区域。

工作台完成初始快照、项目列表与首屏布局后才通知启动页退场；正常退场约 180 ms，不强制等待完整品牌动画。首屏确认等待最多 15 秒，退场确认最多 250 ms。启动中可关闭应用，退出后不会再次显示迟到的主窗口。开发服务下可打开 `http://localhost:5173/startup.html` 单独查看动画，添加 `?theme=dark` 查看深色；浏览器预览隐藏原生关闭按钮。

```text
[Pi GUI] ──┬── 界面 ── Vue 3 组件与响应式展示
           ├── 业务 ── Controller 与纯会话投影
           ├── 通信 ── AgentPort 契约与 Electron 适配器
           └── 执行 ── SDK 宿主复用现有 AgentSession
```

`packages/tui` 负责终端输入与渲染；实际会话消息链路在 InteractiveMode。GUI 对照其输入分派和事件订阅，Vue 不依赖终端组件，业务契约不依赖 Electron。

**当前可用范围**

已支持项目选择、新对话、流式聊天、可折叠推理与工具结果、模型和思考等级切换、API Key 保存、深浅主题。运行中的过程摘要会在「正在分析请求」后追加最新思考片段，随流式内容持续更新；分析、运行命令、调用工具、已完成和已思考使用各自图标。输入框模型菜单折叠时只显示当前模型名称；打开后先选择已认证的模型提供商，再选择该提供商下已认证的模型，未配置 Provider 和模型不会出现在列表中。侧栏按工作区组织项目，并在项目下展示最近会话；每个工作区右侧可重命名、删除（仅从侧栏移除）或新建会话。可切换项目、跨项目打开历史会话，并搜索、重命名、置顶与归档各工作区会话。运行中的回合用一行显示正在分析、运行命令或调用工具，过程默认收起，底部显示用时；已完成的回合收起为带用时和操作摘要的行，点击摘要行显示或隐藏操作摘要，点击操作摘要展开步骤列表，每次最多显示 12 行，更多步骤滚动查看。草稿按会话保存；未发送的空会话也能在重载和应用重启后恢复原身份。Renderer 重载可恢复在途状态，宿主异常退出后可重新打开项目恢复已落盘内容。

每个已打开会话保留独立宿主，支持多个会话同时运行。运行中可以切换项目、新建或浏览其他会话并提交任务；插件页和自动化页中点击会话标签即可返回。消息、队列和草稿按会话隔离，侧栏按会话显示运行与断开状态，停止只作用于当前会话。加载扩展不显示任务转圈。同目录会话共享工作区文件，文件隔离可用独立工作树。详见 [多会话运行](docs/multi-session.md)。准备阶段暂不可取消。右侧「变更」提供 Git 分支/状态、Monaco 文件差异、行评论、带版本校验的暂存/取消暂存/还原、独立 PTY 终端，以及工作树的创建、打开和移除。Git 操作同时核对 HEAD、索引对象和工作区内容摘要，文件仍为修改状态但正文已变化时也会拒绝旧视图；未跟踪文件可以暂存。行评论绑定左右侧、行号和差异版本，发回草稿前再次校验。工作树打开时验证其属于当前仓库；移除前检查 HEAD、未提交改动和忽略文件，分支会保留。

会话标题行右侧可展开工作区面板：开始页提供变更、工作区文件、终端和浏览器入口，打开后以标签页展示。标题行不再单独显示「变更」按钮，统一从右栏开始页进入。左侧栏展开或收起只改变布局，右栏标签、文件预览、终端实例和原生网页状态继续保留。窄栏上下排列文件列表和差异，Monaco 自动使用行内差异，放大后恢复并排；工作树表单和操作栏随实际容器宽度排布。面板支持拖拽分界线调整宽度、放大、收起到标题行，以及 `Ctrl+P`、`Ctrl+\``、`Ctrl+T` 快捷键。文件浏览只读取当前项目目录，终端使用独立 PTY。

工作区文件中的图片可打开独立预览标签，支持缩放、原始大小和适应窗口。Agent 成功读取图片后，步骤显示“已查看 X 张图片”；点击展开后在下一行显示缩略图。图片来自 SDK 已返回的工具结果，不重新读取原文件，应用重启后可恢复。详见 [图片预览与查看步骤](docs/image-preview.md)。

右侧浏览器使用 Electron 原生 WebContentsView，可在工作台内浏览 HTTP / HTTPS 网站和本地开发页面，不受 iframe 嵌入限制。地址栏支持回车与打开按钮，提供前进、后退、刷新、停止、页面标题、加载状态和失败重试；`localhost:5173` 等本机地址自动补 HTTP，普通域名默认 HTTPS。新窗口链接在当前浏览器标签打开；切换标签或返回开始页保留页面输入，关闭标签、关闭侧栏、切换项目和重载工作台释放网页。设置、菜单等弹层显示时暂时隐藏网页，关闭后恢复；拖拽分界线时让出指针区域。

网页使用独立持久化 Session，登录信息与工作台隔离，不加载桌面 preload，不接触 Node 或 Pi 业务桥；设备和系统权限默认拒绝，文件与系统协议不能导航。下载链接保留原网页并提示在系统浏览器中下载，右上角外链按钮只在点击后打开系统浏览器。网页获得焦点时，已登记的工作台快捷键仍可打开设置和侧栏工具。

左上角「编辑」为分组菜单：撤销、重做；剪切、复制、粘贴、删除；全选；设置，并显示对应快捷键。编辑操作恢复打开菜单前的输入焦点或文字选择，再交给 Chromium 原生命令，保留撤销记录；Esc 恢复原焦点，点击菜单外部保留新焦点。设置也可用 `Ctrl+,` 打开，不依赖活动项目。应用快捷键统一放在 `src/domain/app-keybindings.ts`，不拦截系统编辑快捷键。

侧栏「插件」切换到插件页，展示宿主已加载的扩展、技能、提示模板、注册命令和加载诊断；资源由宿主发现，界面不直接读取资源文件。

输入区的「计划」会先把活动工具限制为只读检索工具，生成可编辑的待确认计划；点击「保存修改」持久化编辑，批准后才恢复完整工具并执行。计划文本、状态和原工具集合按会话原子保存，重启后恢复待确认文本与只读限制。生成或执行中断会显示中断状态，须核对历史再批准；不会自动重放。模型失败、取消和停止不会标记为计划完成。

自动化任务页的「并行任务」入口可把独立任务交给后台会话进程。每项任务从来源仓库 HEAD 创建独立工作树与分支，不带入来源目录的未提交内容。最多两个任务同时运行，取消后等宿主释放才补入下一项；工作树准备失败不会回退到来源目录。记录会持久化，重启后未完成任务标记为中断且不会自动重放。模型返回错误时记录失败。完成的任务按实际工作树路径打开原生会话；目录与分支保留供核对，不自动合并或清理。

侧栏「自动化任务」切换到自动化页，按分钟间隔运行后台会话。任务可暂停、恢复、立即运行或删除，并显示最近运行结果和失败原因。任务与运行记录会持久化；应用关闭或电脑休眠后按任务的补跑策略执行一次或跳到下次，未完成任务不会自动重放。

侧栏底部的设置图标打开设置页面：账号与认证概览、通用外观设置、模型与 Provider 认证、MCP、技能、插件和当前 Agent 配置。所有设置分类与使用统计、归档管理共用居中宽度，取可用内容区的 2/3、最大 832 px；窗口变窄时保留对称间距，长表单独立滚动。模型页列出已配置 Provider，可编辑凭据、添加内置 Provider，或通过「自定义 API」填写 Base URL、API 类型、模型 ID 和 Key 接入 OpenAI-compatible、Anthropic 或 Google 接口；自定义模型可启用思考/推理能力。模型页支持删除已配置 Provider：自定义 Provider 会删除 `models.json` 配置和本地凭据，内置 Provider 只移除本地凭据，之后可重新配置；也可直接打开 `models.json`。账号余额和独立 Agent 预设尚未接入。

服务商设置支持 Pi ModelRuntime 中的 OAuth 登录、退出和重新登录。登录方式选择、设备码、浏览器链接与手工授权输入均由 Provider 交互产生。授权码只作为交互回复交给宿主；access / refresh token 不进入快照、聊天或草稿。登录总时限十分钟，单个交互默认五分钟，可取消；浏览器回调完成时可单独关闭手工码提示，不取消整个登录。关闭设置后仍有登录进度与取消入口；Renderer 重载保留正在等待的交互，应用重启不恢复未完成登录。登录成功后等待异步模型刷新，凭据仍按原格式保存在 Pi 的 `auth.json`。

已加载当前 Pi 配置中的扩展。桌面 UI 覆盖 select、confirm、input、editor、notify、setStatus 和文本 setWidget。弹窗有超时与信号取消，界面重载可继续回复；旧请求和旧宿主回复会拒绝。浏览会话不会销毁原扩展运行时；分支前仍调用来源扩展的取消钩子，取消后保留原会话。终端组件工厂、原始终端输入、自定义页眉页脚、主输入框替换与终端主题控制不在此范围；界面会提示不支持。扩展命令仍经 SDK prompt，可直接输入已知命令；资源启停、重载和命令菜单尚未提供。

消息可复制正文原文，保留 Markdown；推理和工具结果不混入正文。代码块独立复制解析后的代码，保留缩进、内部换行和尾部空行，排除围栏与其前一个结构换行。复制失败可重试；超过 200 万字符会拒绝，不截断。传输前已截断的超长正文会明确提示，只展示纯文本，不提供整段或代码块复制。不读取系统剪贴板。

已有助手历史之后的纯文本用户消息可“从此消息分支”。新会话保留此前历史，把选中文本放回草稿并聚焦输入框，不自动发送。来源链接可返回原会话；两边的后续消息、草稿和队列独立保存。首条消息、图片消息和超过 100 万字符的输入暂不提供分支。初始化、草稿或索引保存失败时保留原活动会话，已生成的新分支文件不删除。

空闲时点击“引用文件”，用原生对话框选择当前项目文件。每次最多 20 个，解析目录链接后检查真实归属并去重；项目外文件、目录、失效文件和异常路径整批拒绝。相对路径以 `@"src/中文 文件.ts"` 写入草稿，保留已有文字与空白，并随草稿跨切换、重载和重启恢复。取消和超限不改输入，保存失败保留可见内容。引用只提供文件路径，模型发送后仍需用 `read` 等工具读取。图片由独立入口添加。

也可点击输入区搜索图标，按文件名或项目相对路径查询，再用鼠标或键盘选择一项引用。搜索不区分大小写，接受中文、空格和 Windows 路径分隔符，查询最多 200 字符。按 Enter 只选择文件，不发送任务；关闭后不改草稿，插入后恢复输入焦点。查询失败可重试或改用原生文件选择，选中时会重新检查文件是否有效。

搜索只扫描当前项目，遵守项目内逐层 `.gitignore`，跳过链接、`.git` 和 `node_modules`；不读取文件正文，不依赖 fd。每轮最多扫描 10000 条目录项、32 层，扫描预算 2 秒，最多显示 20 条候选。达到上限或部分目录不可访问时提示结果不完整；不包含全局和父目录忽略规则。搜索弹窗与行内补全共用此查询接口。

也可在输入框键入 `@src/中文`，或用 `@"src/带空格的路径` 查询带空格的文件名。上下键选择候选，Enter 或 Tab 引用，Esc 关闭候选并保留焦点，Shift+Enter 换行。补全替换光标所在片段，保留前后正文，并把光标放回引用之后。邮箱、文本选择和跨行片段不触发补全。查询中或没有结果时，Enter 保留输入；没有候选时 Tab 仍可离开输入区。长按确认键、组词及刚结束的候选确认不会续发任务。

行内引用继续复用文件重验和草稿保存。文件失效、草稿变化或会话更换时拒绝旧选择；取消、关闭与重新编辑不会留下旧候选。键位集中登记在 `src/domain/editor-keybindings.ts`，组件支持覆盖配置；当前设置页尚未提供键位编辑。

支持图片的模型可用“添加图片附件”选择 PNG 或 JPEG，也可在输入框粘贴截图或拖入图片，需同时填写文字说明。每份草稿最多 4 张，每张原文件及重编码结果最多 3 MiB，最长边 8192 像素，总像素不超过 1600 万。主进程先检查签名和尺寸，再完整解码并统一转成 PNG 保存本地副本，草稿只存 ID；原文件删除、重载或重启后仍能预览。图片可放大、重试预览或从草稿移除，编辑文字不会重复读取图片。移除只删草稿引用，当前不自动回收内容库文件。

粘贴只读取当前事件提供的图片文件，不轮询系统剪贴板。纯文字粘贴和拖放保留浏览器行为；含文件时只处理图片，不插入附带的路径、HTML 或远程链接。图片与普通文件混选、伪造图片、超量或超大输入整批拒绝，保留原草稿。读取和导入期间阻止发送与会话切换；成功后恢复输入焦点。普通项目文件仍使用“引用文件”。

图片输入先保存草稿，再交给 SDK。空闲发送在原调用正常结束后清理原草稿；排队或引导在内容和写前记录保存、SDK 接受后清理。运行中也可添加图片。队列显示附件数量，图片沿用会话内容 ID，不复制 base64 到快照。中断后只保留待核对记录；恢复同时保存文字和图片，再清空队列。合并超过四张或草稿长度上限时保留队列，不丢附件。重载或宿主中断后须核对聊天记录再决定是否重发；不会自动重发或承诺跨崩溃只执行一次。聊天历史按需显示规范 PNG 预览，旧历史中的其他格式明确占位。

聊天事实继续存于 SDK JSONL。置顶、归档、当前会话身份和草稿存于 Electron userData 下的 `workspace/`，草稿与索引分开原子写入。保存失败会保留输入并阻止切换，旧修订不能覆盖新草稿。SDK 尚未落盘的空会话由桌面索引保留，不插入虚假消息。

任务运行时，Enter 或“排队”追加后续任务，“引导”交给 SDK steering 队列。准备、重试、压缩和保存阶段暂不接收追加。每轮最多追加 20 条、合计 200 万字符。停止先撤下待处理队列，再取消当前任务。空闲时可整体恢复到输入或清空；恢复先保存草稿，不自动发送。暂不支持单条编辑或删除。

排队意图先保存到独立写前文件，再交给 SDK。正常退出和宿主崩溃后提供待核对记录。中断记录可能包含已处理输入，须结合聊天记录核对；不会自动重放，也不承诺跨崩溃只执行一次。原有待处理内容未整理前，不能直接启动下一任务。

安装包启用 asar，宿主入口和原生模块放在 asar 外；SDK 的主题与资源复制到 `resources/sdk`，主进程在 packaged 模式下把 `PI_PACKAGE_DIR` 指向该目录。Debian 系安装命令为 `sudo apt install ./Aniao-Harness-<版本>-linux-amd64.deb`。桌面快捷方式与命令 `aniao-harness` 均可启动。
