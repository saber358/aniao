**GUI 架构约束**

视觉方向：低对比中性色工作台，用间距和文字层级组织内容，只保留一个操作强调色。

内容结构：项目与会话导航、会话正文、底部输入区，以及已接通的工程辅助面板、资源页和自动化页。

交互方向：菜单和弹窗使用组件库的焦点管理；面板切换保持阅读位置；减少动画偏好关闭非必要过渡。

```text
[业务边界] ──┬── renderer ── Vue 与第三方组件
             ├── domain ── Controller 与不可变投影
             ├── shared ── 数据协议与端口
             ├── main / preload ── 桌面传输与窗口
             └── host ── Pi SDK 与会话事实
```

- shared/domain 不导入 Node、Electron、Vue、UI 库或 Pi SDK。
- Renderer 不导入宿主实现，只消费 AgentPort 和 ViewModel。
- 跨进程数据从 unknown 开始校验。请求 id、会话 id、宿主代次和事件 seq 不互相替代。
- 事件缺口拉取快照；不自动重发命令。界面释放订阅不结束独立宿主。
- 消息与工具更新是累计快照替换；Agent 循环结束和任务收束分别处理。
- logger 只记录生命周期，不记录提示词、凭据、工具参数或输出。
- 第三方消息类型留在 renderer 适配层。组件升级不修改业务协议。

免费内置 MCP 使用官方 MCP 扩展和内存传输，宿主通过关联的反向消息调用主进程。主进程再次校验服务、工具、开关和宿主身份；浏览器控制仅指向所属会话的原生网页，网页没有业务桥或任意调试端口。多个标签按会话保留，动作按标签排队，取消与退出撤销等待。免费网络工具无认证头或浏览器 Cookie，只读公开来源。外部 MCP 仍由 SDK 创建标准 stdio/HTTP 传输；连接观测不替换 SDK 管理器。详见 [免费内置 MCP](docs/builtin-mcp.md)。

**当前实现**

```text
[用户操作] ── GuiController ── AgentPort ── preload IPC
                                              └── 主进程 ── utilityProcess ── AgentHost
                                                                                 └── AgentSession
[会话事实] ── SessionAdapter ── 归一化事件 ── SessionProjection ── Vue
```

main 与 preload 由 electron-vite 输出 CJS。宿主独立由 esbuild 输出 ESM，保留 SDK 的 `import.meta.resolve` 语义。桌面内核使用固定的官方 Pi `1.4.0` 发布包，四个核心包和 TypeBox 版本同步；开发、测试、宿主构建统一解析本包依赖，不再引用仓库 `0.80.6` 源码。宿主启用 `PI_BUNDLED_NODE`，复用官方虚拟模块加载扩展；相对文件和其他依赖仍从扩展目录解析，缓存与资源重载沿用上游实现。官方发布包的 OAuth、Bedrock、图片处理与 codemode 工作线程独立文件显式复制到宿主旁，避免变量导入打包后丢失。主进程为宿主指定同版 SDK 资源目录，开发模式使用官方包目录，打包模式使用 `resources/sdk`；原生模块与主进程运行文件放在 asar 外。`0.80.10` 发布包已核对四个 Pi 依赖、SDK 资源与十二个官方独立模块，并在真实宿主中核对版本与 OAuth 延迟模块。

StartupWindow 在桌面服务初始化前加载独立的 `startup.html` 与 `startup.cjs`，不依赖 Vue、SDK 或通用业务桥。启动页只持有就绪、关闭、退场确认和状态订阅能力，主进程校验所属窗口与 main frame。工作台先隐藏，初始会话快照、项目列表和 Vue 首屏布局完成后用固定的零参数通道通知主进程；错误状态也可交接，恢复失败提示在工作台显示。确认等待最多 15 秒，超时报错而不露出空白主窗；退场确认最多等 250 ms，正常 CSS 退场为 180 ms，不以完整品牌动画时长阻塞启动。系统减少动态效果时立即确认。退出处理在启动页显示前注册，每个服务创建后登记清理；启动中关闭会解除等待、移除 IPC 并阻止迟到结果显示主窗。开发和生产配置均包含两个 preload 与两个 HTML 入口。

```text
[桌面启动] ──┬── 启动页 ── 本地品牌与加载状态
             ├── 工作台 ── 隐藏加载与首屏确认
             └── 交接 ── 短退场后显示工作台
```

协议由 Zod schema 推导。线上的数据是归一化消息、工具、运行状态和模型配置，shared 不引用 SDK 类型。工具按所属助手消息与 toolCallId 关联；32 ms 内合并累计进度，关键事件前冲刷，发出时分配连续 seq。没有保存结果的历史工具调用显示未完成。

准备阶段与可取消的 SDK 运行分开。准备失败不产生 agent_settled，宿主主动恢复空闲。运行中的停止先请求取消，再等待收束。空闲取消不改变状态；旧代次命令被拒绝。纯文本发送被接受后只清理原草稿一次，用户随后输入的相同文本也不会被清除。

GUI 每个 profile 只启动一个应用实例，WorkspaceService 按会话保留独立宿主，多个普通会话可以同时运行；后台调度仍有独立的两个并发名额。切换只改变当前选择，返回已有会话复用相同宿主代次，不关闭原任务。SessionControllers 按 sessionId/generation 保存独立 GuiController，命令、消息、队列和草稿各自归属原会话。跨会话事件携带身份，故障只断开对应会话；侧栏接收有界运行摘要。Renderer 重载只释放订阅；应用退出等待所有宿主、调度器与 PTY 的关闭结果，单项保存失败不跳过其他回收。宿主有 5 秒收束时间，随后终结受管进程。宿主异常后保留展示与草稿，用户重新打开会话恢复 JSONL，不自动重放 prompt。详见 [多会话运行](docs/multi-session.md)。

WorkspaceService 负责会话切换与组织操作互斥，新宿主初始化失败时保留旧宿主。历史选择携带来源宿主身份，项目切换后迟到的选择被拒绝。SessionLibrary 用 SDK 发现当前 cwd 的历史，只向 Renderer 返回摘要和 ID，不传原生会话文件路径。重命名写入 SDK，置顶与归档由桌面保存。

ProjectFilesPort 只接受 sessionId 与 generation，原生文件对话框由 main 持有。WorkspaceService 在选择前锁定空闲会话，阻止发送和切换，返回前再次检查宿主、代次与运行状态。文件经 realpath 解析后用相对路径检查归属，拒绝项目外文件、越界链接、目录、失效文件和控制字符；最多 20 个、每条最多 4096 字符。全部有效才返回去重的项目相对路径，不读取正文，不记录路径负载。文件选择的归属校验不限制 SDK 工具的文件访问权限。

文件查询端口额外接受最多 200 字符的字面量查询；不接受 cwd 或绝对路径。主进程逐目录异步扫描，使用 ignore 7.0.5 解析项目内逐层 .gitignore，不依赖 fd 下载。单次扫描最多 10000 条目录项、32 层，扫描预算为 2 秒；预算在文件系统调用之间检查，不保证中断操作系统等待。单份规则最多 64 KiB，累计最多 256 KiB。规则读取失败明确报错，不静默忽略。查询跳过链接、.git 和 node_modules；不读取全局忽略规则和项目外父目录规则。最多返回 20 条相对路径，扫描受限或部分目录不可访问时标记不完整，不能解释为完整文件索引。新查询、会话切换和退出会取消旧查询，返回前复核活动宿主。选择后再次解析真实路径，文件删除或被替换为越界链接时拒绝引用。

ProjectFileSearch 复用 Nuxt UI Modal 与 CommandPalette 管理焦点和键盘，按 main 返回顺序显示全部有界候选，不再次模糊过滤。相对路径用文字插槽展示，避免文件名作为 HTML。useFileSearch 只持有查询状态，180 ms 合并输入，监听会话、代次与查询原始值；关闭、查询变化和销毁立即撤下旧候选并丢弃迟到响应。选中后调用 Controller 的同一引用入口，不发送 prompt；保存期间禁用重复选择，校验失败保留弹窗与草稿，草稿保存失败由输入区显示并保留内容。关闭焦点事件接管成功路径，取消仍恢复搜索按钮；弹窗退出后才恢复输入焦点或打开原生选择。行内补全复用同一搜索和引用通道。

Controller 的 selectingFiles 状态阻止重复选择、提交和队列恢复；Vue 同时禁用会话切换入口。选择返回后再次检查会话、代次、连接与草稿归属，按返回时的最新输入合并引用，保留已有空白。路径用 JSON 字符串转义形成 `@"相对路径"`，只作提示词文本，不进入 shell。合并超过 100 万字符时整批拒绝；保存复用原有串行草稿通道，失败保留输入，不增加附件状态或第二份存储。草稿、提交和分支共用无 Zod 依赖的上限常量，Renderer 不因引用功能引入协议校验运行时。

file-completion 在 domain 中按 UTF-16 光标提取有界 @ 片段，区分普通路径与带空格的引号路径，不依赖 DOM。Controller 可附带此片段调用同一引用方法，选中前后都检查原草稿；变更时拒绝覆盖。替换只使用主进程重验后的单个相对路径，保留前后原文。光标信息和草稿快照只留在界面与业务层，不扩充文件 IPC 或 SDK 发送协议。

ComposerFileCompletion 复用现有 ChatPrompt 与 Nuxt UI Button，不更换编辑器或复制消息发送链路。useFileCompletion 在 textarea 捕获阶段处理候选动作，方向键只改变当前候选，Enter 和 Tab 只请求引用。没有结果时 Enter 不发送，Tab 可以离开；Esc 只关闭当前输入版本，编辑后重新查询。组词及结束后 50 ms 内的确认不进入发送处理；长按确认在候选关闭后仍被拦截，释放后才恢复常规输入。默认键位集中在 DEFAULT_EDITOR_KEYBINDINGS，组件可覆盖或禁用动作，暂未提供设置页编辑。节点、会话或代次变化时释放监听和计时器，销毁后的选择不恢复旧焦点。候选使用 listbox、选中状态与 aria-activedescendant，文件名仅作为文字。

图片通过独立 ImagesPort 选择和按需预览。支持 PNG 和 JPEG，每张原图及重编码结果不超过 3 MiB，最长边 8192 像素，总像素不超过 1600 万，每份草稿最多 4 张。文件读取有固定上限，先查签名、PNG IHDR 或 JPEG 帧头与像素边界，再由 Electron 完整解码并统一重编码为 PNG。JPEG 接受 8 位基线、扩展顺序和渐进帧；截断或未知帧拒绝。ImageStore 按 cwd、sessionId 隔离内容文件，以规范内容摘要定位，原子保存后才返回 ID；读取再次检查摘要。图片不随文字按键重复保存，原文件删除后仍可恢复。选择或保存失败可能留下无引用内容，当前不自动回收，避免删除在途或其他草稿仍引用的图片。

ImagesPort 的内容导入只接受当前会话身份和有界 base64 批次，不接受路径、URL 或目标目录。preload 与 main 双向校验协议；WorkspaceService 复用选择互斥、模型能力检查和返回前身份复核。ImageStore 的文件与内容入口共用逐张校验、原生解码与原子保存流程，不另建图片库。

ImageInputZone 只处理输入区 paste / drop 的 File。纯文字事件不拦截；含文件时阻止默认导航与路径插入，不读取附带 HTML 或 URL。文件引用在事件内同步捕获，Controller 建立 selectingFiles 互斥后才调用读取器；Renderer 先检查整批元数据，再逐张有界编码。MIME 与扩展名仅作早期提示，主进程重新核对内容并完整解码。读取后先复核会话与连接，再提交内容；销毁或换代结果不导入草稿。原生选择、粘贴和拖放共用同一草稿确认和图片预览。

宿主根据模型实际 input 能力拒绝不支持的图片请求，读取当前会话内容后传给 SDK。图片消息快照只含 ID，预览通过关联请求按需读取 SDK 当前历史；不把 base64 放入每条流式快照。旧历史中的其他格式、过大图片仍保留在 SDK JSONL，GUI 只显示明确占位。文字与图片排队共用同版 SDK 输入钩子、技能和模板展开。纯文字保留即时扩展命令语义；带图输入和队列编辑拒绝即时命令。扩展改写的 PNG 先校验并保存，再用同一正文与图片更新核心消息、投影和恢复记录；不支持的图片格式明确拒绝，原队列不变。

QueueItem 同时携带稳定条目 ID、文字和可选图片 ID，写前文件按同一形状保存。宿主同步提交后精确安装 SessionAdapter 映射，普通消费按两类 FIFO 各自撤下队首，GUI 不按正文匹配附件。编辑、删除和引导使用条目 ID，不把旧下标用于新队列；编辑失败或目标已消费时保留编辑框正文。停止与收束保留原图片身份，重启不重新注入 SDK。空闲队列显示恢复与清空入口；恢复先检查合并文字和去重图片上限，再保存同一草稿，最后清空队列，失败重试不重复追加。活动任务期间可选图和导入，切换和提交仍与导入互斥。

Controller 将图片 ID 纳入同一草稿修订与串行保存。图片发送前等待保存成功；SDK 首个助手消息前可能尚未落盘，因此图片草稿保留到原窗口的 prompt 调用正常结束，再按文字与图片身份同时核对后清理。新输入、重载和宿主中断后保守保留，不靠相同文字猜测跨重启确认，不自动重发。ImageAttachment 在草稿和历史中复用，只监听会话、代次、内容 ID 与来源的原始值；文字和流式更新不重复取图。预览通过 Nuxt UI Modal 展示，组件销毁或身份变化后丢弃迟到结果。

分支选择经 WorkspacePort 携带 sessionId、generation 与原生 entryId。SessionAdapter 按 SDK 消息对象身份关联原生 entry，不用正文、显示 ID 或数组位置推测；message_end 早于 SDK 持久化，入口在任务收束后补全。只开放当前上下文中已有助手前缀、非空、纯文本且不超过草稿上限的用户消息，保证新 JSONL 可以立即恢复。

新分支宿主先读取来源 SessionManager，再对选中 entry 的 parentId 调用 SDK `createBranchedSession`，最后用共享运行时工厂初始化新会话。SDK 在恢复缺少思考配置的旧文件时可能补写元数据，因此不先初始化来源运行时。分支前请求来源空闲宿主调用 session_before_fork，扩展返回 cancel 时不建立新宿主；普通导航不触发原运行时的切换或关闭回调。初始化失败时新原生分支文件保留，原活动宿主不变。

宿主 ready 只额外返回受限的初始草稿，不污染 AgentPort 快照。WorkspaceService 核对新会话身份、持久化状态和 parentId，先保存草稿，再更新活动索引；原宿主继续保留。保存失败保留原会话；新文件与已保存草稿供后续恢复，不做跨文件事务或自动删除。来源路径在 SessionLibrary 内转成当前项目会话 ID，界面只展示可查证的来源链接。新分支不自动发送，也不继承来源草稿或待处理队列。

WorkspaceStore 用串行读改写和临时文件同步后替换保存索引与草稿。草稿文件按 cwd 与会话 ID 的摘要定位，并检查修订；损坏文件保留原文且拒绝覆盖。Controller 合并在途保存后的后续编辑，保存失败阻止切换。SDK 首个助手消息前不会落盘，未发送会话由索引保留 ID，恢复时用相同 ID 重建空会话；已落盘历史缺失时拒绝伪装为空会话。

排队和引导走同一 AgentPort。`host/kernel-queue.ts` 集中适配固定 Pi 1.4.0 的展示字符串与核心待消费对象：输入异步准备，写前保存后再次检查状态，最后同步追加或修改单条对象，不清空和重放整个活队列。单条修改在准备前捕获原生对象，提交时重验仍未消费；核心已 drain、展示尚未撤下的在途条目同样拒绝。内部结构不符时拒绝修改，升级内核必须重跑队列并发回归。队列快照和 `queue_update` 经归一化事件同步。入队和单条修改共用互斥，独立于长 prompt；Controller 用每次提交的局部身份确认草稿，旧调用结束不能确认新提交。恢复先保存输入后清空。

QueueJournal 与 WorkspaceStore 共用 `storage/atomic-json.ts`，队列写前文件按项目与会话摘要隔离。输入钩子处理后的实际正文及附件先保存，再次检查 streaming 状态后同步入队，迟到输入不能启动新任务。编辑原位修改恢复记录，引导追加到引导队尾；异步保存期间目标被消费或任务停止时撤销该条修改。运行中保留本轮其他已接收记录，SDK 收束后才检查剩余队列；持久化结束前展示 settling。每轮累计追加上限为 20 条、200 万字符。

SDK 的 abort 可能继续消费后续队列。宿主先同步 clearQueue，保留当前写前记录供核对，再 abort 并等待收束。保存失败时保留旧文件和可见记录，关闭仍释放订阅与运行时。重启不会把写前记录重新注入 SDK；记录可能已经处理，用户须先恢复到草稿或清空。恢复文件不提供跨崩溃只执行一次的保证。

Electron 启用 contextIsolation 和 sandbox，关闭 Renderer Node integration。主进程校验窗口及 main frame。Markdown 禁用默认扩展语法，使用标签和协议白名单。外链只允许 http、https、mailto，主进程再次校验。API Key 专用写入 AuthStorage，不进入快照、聊天或日志。

BrowserManager 按会话身份管理多个 BrowserService，每个服务单独持有原生 WebContentsView，网页不在 Renderer 的 iframe 或 WebView 中运行。`shared/browser.ts` 限定地址、固定浏览动作、布局和状态；preload 与 main 校验 schema，手动操作来自工作台主框架，模型操作来自绑定原宿主的 MCP 反向通道。网页使用 `persist:harness-browser` Session，持久化网站登录，与工作台和 Pi 认证分离；不加载 preload、关闭 Node 和 WebView，权限检查与请求均默认拒绝。用户导航和重定向只允许 HTTP / HTTPS；新窗口请求始终拒绝创建额外窗口，合法地址改在当前视图打开。导航状态由 Chromium 历史和主框架事件提供，旧标签或迟到加载失败不能覆盖当前标签。

BrowserPane 用 ResizeObserver 和合并到同一帧的 DOM 观察同步占位区域，主进程按工作台缩放换算坐标并裁到内容区域。原生网页不参与 DOM 层叠，设置、菜单与候选列表可见或正在拖拽分界线时主动隐藏；切换工具、会话、项目、开始页或收起侧栏均保留实例，关闭标签、重载主窗与退出释放原生 WebContents。后台新标签先有 1024 × 768 隐藏视口，前台展示时采用实际右栏尺寸；后台截图不会把隐藏网页唤到前台。下载默认取消，恢复已提交网页并显示系统浏览器入口；外链仍需用户明确点击。网页原生键盘事件用统一 DEFAULT_APP_KEYBINDINGS 解析，匹配的工作台动作转交原有界面入口。

```text
[内置浏览器] ──┬── 地址与控件 ── BrowserPort 校验
               ├── 原生网页 ── 独立 Session
               └── 面板生命周期 ── 布局、隐藏与回收
```

DialogService 为 OAuth 和可移植扩展弹窗持有回调。跨进程只传请求 ID、展示参数、截止时间和回复；会话身份与宿主代次继续由命令 Envelope 核对。默认五分钟，最长十分钟，同时最多八个请求；超时、AbortSignal、关闭均走同一清理路径。快照携带未答请求，重载可恢复；回复不存草稿。Renderer 只显示首个待答请求，完成后再显示下一项。等待输入单独展示；取消和回复绕过长命令互斥。

AuthService 从 ModelRuntime 读取 OAuth 服务商，把新版 `prompt` / `notify` 交互映射到桌面弹窗。宿主等待 Provider 登录返回后复核取消信号，再用 CredentialStore.modify 串行保存，避免忽略取消信号的迟到凭据落盘。存储沿用官方 AuthStorage 的文件锁和原 `auth.json` 格式；内部存储与主题导出集中放在 `host/kernel.ts` 适配边界。登录总时限十分钟，取消即终结桌面等待；单个手工码提示可被浏览器回调单独取消。Provider 负责回调服务器与轮询清理。浏览器地址只允许 http / https，错误不透传原始负载。成功、退出或 API Key 变更后等待 ModelRuntime 异步刷新，快照只带注册表摘要、登录进度和认证布尔值；应用重启保留凭据，不恢复未完成流程。

ExtensionUI 对照 RPC 的 ExtensionUIContext，支持 select / confirm / input / editor、通知、状态和文本小组件。通知最多二十条，状态和小组件各最多二十项；小组件最多四十行，每行 4096 字符。文本去除 ANSI，只作文字渲染。终端工厂、原始输入、主题切换和主输入框替换不传给 Vue，并明确提示不支持。supported 字段声明当前能力；ctx.mode 使用 rpc，未更改核心模式类型。

SDK 资源仍按用户选择并信任的项目与既有 Pi 配置发现扩展。宿主先报告传输 ready，再异步绑定 session_start，初始化弹窗可用当前身份回复，避免启动等待 UI 时双方互相等待。WorkspaceService 在切换钩子期间只放行回复、取消与通知关闭；退出会关闭待接替宿主，阻止迟到切换创建新进程。新宿主接收 new / resume / fork 启动原因。资源摘要与诊断已进入会话快照；扩展发起的会话替换和终端组件仍未提供。

MCP 配置修改由 WorkspaceService 在写文件前锁定当前空闲宿主；运行、交互、在途命令或待批准计划期间拒绝修改当前宿主。McpService 串行读取、原子写入并等待 `reloadResources`，SDK 重载后发布资源快照；重载失败则还原配置并重载原资源，恢复失败提示重新打开项目。重载期间保留扩展回复通道。没有活动项目时只保存全局配置；其他空闲宿主同步重载，正在运行的宿主在收束后更新，下一任务前再次核对资源修订。MCP 连接由 SDK 在后台完成，配置已重载不代表连接成功；传输观测把实际连接状态、工具数和脱敏错误提供给设置页，并保留 SDK 原有通知。

反馈弹窗不包含账号登录、注册或令牌读取。`feedback-client.ts` 只在点击提交后向反馈 API 发送 multipart，明确省略 Cookie 与 Authorization；正文最多 5000 字，最多 4 张、每张 5 MB 的 PNG/JPEG/WebP/GIF。失败保留正文和图片，关闭弹窗也不清空，成功后才释放预览与表单；卸载取消请求。配套后端允许匿名 POST，匿名记录不绑定用户，后台管理仍鉴权；旧 H2 的 `feedback.user_id` 非空约束由启动迁移幂等移除。

GitService 把 HEAD、选中文件的索引对象、工作区内容摘要、模式和链接目标合成差异版本。读取前后再次核对，避免返回混合版本；暂存、取消暂存和还原同时要求该版本与原状态吻合。行评论保存原路径、左右侧、暂存范围、行号与差异版本，Monaco 保留最后聚焦侧，发送前重验所绑定版本。未跟踪文件允许暂存。该检查不能把外部 Git 写入变成跨进程事务，操作期间仍应避免多个写入者。
