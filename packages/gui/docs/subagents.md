# 子代理详情

右栏通过当前会话注册的 `subagents-inspect-rpc` 命令读取子代理详情。宿主直接调用命令处理器，不启动模型回合，也不等待主任务结束。插件负责核对子任务归属，并返回任务、消息窗口、最终输出和实际模型。

`subagent-inspect` 组件仅传递带 `requestId` 的结构化回复，不显示在界面中。回复必须在五秒内到达。组件随后撤回时，只结束该次回复，不清空子代理运行树。

右栏同时读取完整转录。`step:N` 按从零开始的 `childIndex` 匹配；工作流业务键先从当前会话工具结果映射到子运行。无法确认归属时返回无记录，不借用其他任务内容。没有完整转录时，用官方消息窗口展示任务、工具和结果。

运行中的详情在上次读取完成后间隔 2.5 秒刷新，进入终态时再读取一次。切换任务或关闭标签后，迟到结果不会更新视图。状态组件撤回后，已读取的对话仍可查看；官方详情仍报告运行中时继续刷新。

查询失败、记录已清理、任务不属于当前会话与尚无消息分别提示。失败时保留已读取内容，并提供重试。插件接口未加载时提示重载会话资源，不把查询文本交给模型。

官方消息窗口最多 200 条，序列化回复最多 64 KiB。完整转录最多传输 2,000,000 字符，输出最多 500,000 字符，截断提示计入上限。该详情视图使用轮询，不提供主 Agent 那样的逐字流式刷新。
