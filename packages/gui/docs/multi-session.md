# 多会话运行

页面导航与任务执行分开。插件页、自动化页中点击当前会话标签即可返回对话。一个会话运行时可以打开、新建或浏览另一个会话，并向另一个空闲会话提交任务。

WorkspaceService 为已打开的每个会话保留一个独立 utilityProcess。切换只是选择另一个宿主，不关闭、暂停或重建原会话。再次打开已保留的会话时复用相同宿主代次。新宿主创建或索引保存失败时，原会话继续保留。

SessionControllers 为每个 `sessionId + generation` 保存独立 GuiController。消息、工具、队列、提交等待和草稿各自归属原 Controller。后台任务结束或报错不会清空当前会话草稿，也不会解除另一会话的提交等待。工作台重载后重新订阅主进程已保留的宿主，不重放任务。

命令始终携带会话 ID 和宿主代次，主进程按身份选择宿主。快照查询同样限定身份。后台宿主退出只通知对应会话；侧栏按会话显示运行或断开状态，不显示“待处理”标签。后台扩展需要确认时，可切回该会话回复。停止按钮只取消当前显示会话的任务。

扩展加载与资源重载使用 `initializing` 阶段，期间阻止提交，但不显示任务转圈、工作中或停止按钮。运行标记只来自真实任务阶段，普通设置命令等待不算任务。宿主登记先订阅，再补读快照；按事件序号拒绝旧状态，避免初始化或任务结束后转圈残留。扩展若启动了实际 SDK 任务，初始化结束不会覆盖其运行状态。

导航不触发扩展的会话销毁或切换回调，因为原运行时仍存在。创建分支仍要求来源空闲，并保留原有扩展取消钩子。文件选择和配置事务保持短期互斥。删除工作区前检查该目录下所有已打开会话，仍有任务时拒绝移除。退出应用会尝试关闭全部宿主，单个保存失败不跳过其他进程。

普通会话在用户选择的目录运行，同目录会话共享工作区文件。需要文件隔离时可以在独立工作树打开会话，或使用自动化页已有的隔离并行任务入口。应用退出会停止进程；重启只恢复会话记录，不自动重放之前的任务。

点击主窗口关闭按钮或按 Alt+F4 会隐藏到系统托盘，会话、网页、终端和后台任务继续保留。点击或双击托盘图标、选择“打开 Aniao Harness”或再次启动应用会恢复原窗口。托盘菜单“退出”才关闭应用并保存全部会话；重启安装更新仍走退出清理。托盘创建失败时保留原有关闭退出行为，避免窗口隐藏后无法打开。启动动画期间关闭仍会取消启动并退出。

验证入口为 `test/multi-session.test.ts`、`test/workspace-run-status.test.ts`、`test/workspace-service.test.ts` 与 `test/gui-controller.test.ts`。真实 Electron 验收先启动 `node scripts/dev-server.mjs`，再运行 `node e2e/multi-session.mjs`。覆盖初始化弹窗期间无任务标记、打开与重启恢复不发送模型请求、两个任务独立转圈和停止。托盘另由 `test/window-tray.test.ts` 和 `e2e/window-tray.mjs` 验证隐藏时任务完成、原窗口恢复、第二实例和菜单退出；后者支持 `PI_GUI_PACKAGED_EXECUTABLE` 指向真实安装包。非默认开发端口使用 `ELECTRON_RENDERER_URL`。验收只调用本机 SSE 模型替身，报告分别保存在 `artifacts/multi-session-*/results.json` 和 `artifacts/tray-*/results.json`。
