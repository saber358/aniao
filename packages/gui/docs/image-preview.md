# 右侧图片预览

展开右侧面板，在“工作区文件”中点击图片，会打开独立图片标签。文件列表保留当前目录，再次点击同一图片会回到已有标签。对话中新建文件卡片的图片入口共用同一预览。

支持 PNG、JPG/JPEG、GIF、WebP 和 SVG，扩展名不区分大小写，单张文件上限为 8 MiB。默认完整显示图片，可放大、缩小、切换到原始大小或重新适应窗口。原始尺寸与缩放比例显示在工具栏。放大后可滚动查看；调整面板宽度或切换标签后，适应窗口模式按实际区域重新计算。

文件读取或图片解码失败会显示错误与“重新加载”按钮。图片修复后可直接重试。文件标签关闭或目标变化后，迟到的读取结果不会写回界面。预览不调用模型。

WorkspaceFiles 只向 SidePanel 提交图片相对路径，FilePreview 调用现有 `previewProjectFile` 端口。主进程核对当前项目，解析真实路径并拒绝项目外文件，再读取有界内容，以 data URL 交给图片元素显示。目录和文本仍沿用原有浏览方式。

验收入口为 `e2e/image-preview.mjs`。先启动 `node scripts/dev-server.mjs`，再在 GUI 包目录运行 `node e2e/image-preview.mjs`；非默认端口使用 `ELECTRON_RENDERER_URL`。脚本使用独立项目、用户目录和测试图片，覆盖图片格式、缩放、标签复用、面板放大与窄栏、深浅主题、损坏与丢失文件重试、大小限制、路径边界及零模型请求。截图和结果保存在 `output/playwright/image-preview-*/`。

## 图片查看步骤

Agent 成功用 `read` 返回图片时，步骤显示“已查看 X 张图片”，默认折叠。连续图片读取合并为一组，展开后在下一行显示相同数量的缩略图；数量较多时横向滚动，不换行。点击缩略图可放大。普通文本读取、失败和运行中的读取保留原步骤，不根据扩展名显示“已查看”。

SessionAdapter 从工具结果保留图片内容摘要，跨进程快照不传 base64。展开时使用当前会话与宿主代次调用图片端口，读取 SDK 已保存的结果，不重新打开原文件或调用模型。支持 PNG、JPEG、GIF、WebP；单次工具结果最多 64 张，单张最多 8 MiB。原文件移除后仍能查看工具返回的内容，应用重启从原生 JSONL 恢复。

聚焦测试为 `test/viewed-images.test.ts`，真实 Electron 验收为 `e2e/viewed-images.mjs`。覆盖默认折叠、连续分组、PNG/JPEG 解码、图片下方单行展示、普通和失败读取、放大、原图删除后的缓存、五张图片与历史恢复。报告与折叠/展开截图保存在 `output/playwright/viewed-images-*/`。
