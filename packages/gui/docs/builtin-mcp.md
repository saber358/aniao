**免费内置 MCP**

「设置 → MCP 服务器」默认提供四项内置服务，无需用户安装 Node、Python、浏览器驱动或填写 API Key。

- `harness_browser`：控制当前会话的右栏网页。支持打开、多个标签、正文与元素快照、点击、填写、选择下拉框、滚动、按键、截图、历史和关闭。
- `harness_web`：读取公开网页正文与免费联网搜索。搜索使用 Bing RSS 和 DuckDuckGo 公开页面，不使用收费 API。
- `harness_docs`：按文档域名检索与读取公开原文。搜索结果仍会核对域名；不承诺自动匹配依赖版本。
- `harness_github`：只读公开 GitHub 仓库、Issue、PR 与文件，使用匿名免费 API。不读取私有仓库，不包含写操作或账号授权。

这些 MCP 不收取服务费用，不自动升级付费额度，也没有收费后备。模型调用仍遵循用户自己的模型计费；免费搜索和 GitHub 匿名接口可能限流、要求验证或暂时不可用，工具会返回明确错误。没有验证码绕过。

**右栏浏览器**

工具控制现有 Electron `WebContentsView`，用户能在右栏看到模型操作，并能直接编辑网页。手动打开的网页也可由所属会话的工具发现。网页继续使用独立的 `persist:harness-browser` 登录存储；网页没有 Node、桌面 preload 或 Pi 业务桥。

每个标签绑定 `sessionId/generation`。模型不能使用另一会话的标签 UUID；没有标签时先调用 `browser_open`。`newTab: true` 新建标签；其他动作传入 `tabId` 可选择当前会话的已有标签。同一标签的动作串行处理。切换会话、收起右栏或左栏不销毁网页；重载整个工作台、关闭标签或退出应用才释放网页。后台任务的浏览器事件不会抢走当前会话。

`browser_snapshot` 返回当前正文和最多 250 个可操作元素。引用只对最近一次快照有效，导航或元素删除后需要重新读取。动作只接受固定参数，不开放任意页面 JavaScript 或工作台调试接口。支持主文档、开放的 Shadow DOM 和同源 iframe；跨域 iframe 给出提示，可单独打开它的地址。Canvas 视觉理解需要支持图像的模型。

点击、输入、选择和截图均经过 SDK MCP 工具管线与既有工具钩子。截图返回 PNG；宽度最大 1600 像素，传输超限会明确失败。取消会撤销尚未开始的排队动作和网络等待，已发出的网页操作不能撤回。

**连接管理**

设置页区分开关与实际连接，展示「等待连接」「连接中」「已连接 · N 个工具」「连接失败」和「已断开」，错误保留说明与重新连接入口。只有打开项目并创建 SDK 宿主后才显示实际连接信息。

全局修改会即时刷新空闲会话；运行中的会话保留当前任务，结束后重载，下一个任务开始前再次检查修订。内置工具额外在每次调用前核对全局开关，停用后旧宿主不能继续通过内置桥调用。外部 MCP 运行中的连接在任务收束后更新。

内置服务可停用，不提供删除按钮。偏好写入用户级 `mcp.json` 的 `harnessBuiltins`，不覆盖 `mcpServers` 或其认证字段。四个内置服务名为保留名称。外部 MCP 继续支持 stdio 和 Streamable HTTP；表单参数每行一个，带空格路径不加引号。高级 `env`、`headers`、OAuth 等字段仍可在用户配置中维护。

**链路说明**

```text
[SDK MCP] ──┬── 内存 MCP 传输 ── 关联请求 ── 主进程校验
             │                               ├── 会话浏览器 ── 右栏原生网页
             │                               └── 免费网络读取 ── 公开来源
             └── 外部 MCP 传输 ── 用户 stdio / HTTP 服务
```

内置服务用 Pi 官方 `createMcpExtension` 注册，沿用 `codemode` 工具发现，避免默认向模型展开全部工具声明。没有额外 HTTP 监听端口或全局 CDP 调试端口。正文单次响应限制 2 MB，输出分段；网络请求不发送浏览器 Cookie、Authorization 或其他本机凭据。

**验收**

`e2e/builtin-mcp.mjs` 用独立配置、本机模型替身和真实 Electron 验证完整工具往返、Unicode 表单、截图、滚动、跨会话拒绝、状态保留、免费正文与连接错误。设置 `PI_GUI_PACKAGED_EXECUTABLE` 可复跑实际安装包。普通测试覆盖 MCP 请求关联、取消/关闭、配置持久化、多会话修订、搜索域名与限流、重定向和读取上限。
