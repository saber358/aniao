**设置中的使用统计与归档管理**

入口为「设置 → 数据与统计」，包含「使用统计」和「归档管理」。页面沿用用户给出的浅灰卡片、分段切换、趋势图、环形图和项目分组，同时适配工作台深色主题与 1100 × 720 最小窗口。按用户最新要求，所有设置页主标题统一为 32 px；卡片标题从 12 px 调为 14 px、正文与控件从 11 px 调为 13 px、说明从 10 px 调为 12 px。指标数值保持 16 px，标签从 9 px 调为 11 px。图表刻度、图例及悬浮提示共用这套字级。

所有设置分类共用居中宽度：内容区取可用宽度的 2/3，最大 832 px。使用统计和归档管理与账号、通用、模型、MCP、技能、插件、Agent 预设保持一致；图表随内容区适配，字号保持设置页统一字级。

趋势图绘图区高 200 px；模型环形图最大直径 180 px，窄窗口为 160 px。两张图表卡片收紧内边距和上下留白，模型明细按实际条数自然展开。

**数据口径**

使用统计只读取本机 SDK 历史，不调用模型，不查询服务商账单，不合并其他设备。未落盘或没有 Usage 的历史不估算 Token。累计值包含 input、output、cacheRead、cacheWrite；reasoning 已属于 output，不重复计算。助手、独立 usage、压缩和分支摘要记录均计入；分支复制的同一条原始用量按身份、时间、模型和 Usage 内容去重。

峰值 Token 是单个会话历史中的最大合计。最长聊天时长是单会话各回合从用户提问到最后助手响应的累计时长，不计两次提问之间的空闲。连续天数按本机日历计算，今天没有活动时当前连续天数为零。热力图覆盖最近一年，趋势图和模型占比共用近 7 日或近 30 日范围。统计刷新后重新扫描磁盘，删除的历史不再计入。

Token 活动悬停或键盘聚焦即显示两行浮层，展示中文日期、当前统计方式下的 Token 和消息轮数。轮数按原始用户提问计数，分支复制去重，工具往返不追加轮数；每周和累计方式同步聚合。每日趋势图的悬浮提示只列出当日 Token 大于零的模型，全零日期不展示模型条目。

扫描在独立 `session-data.mjs` 进程中完成，不创建 Agent 或加载用户扩展。单文件限制 64 MiB，最多扫描 20000 个 SDK 会话；跳过的文件会显示不完整提示。扫描超时、进程退出和损坏返回值均展示错误，保留刷新重试，不能伪装成零用量。

**归档行为**

自动归档和保留时长两行等高，最小高度为 80 px，文字换行时共同扩展。搜索及筛选控件统一高 34 px；工作区组头高 36 px，组间距 6 px，展开后的会话列表仍按内容自然排布。

归档列表来自桌面已登记的工作区索引。支持跨项目搜索标题和预览、按更新时间或名称排序、项目筛选、展开分组、单个或整组取消归档，以及单个、整组和全部删除。操作其他项目不会切换当前会话。

自动归档默认关闭。可选择 7、14、30 或 90 天；启用后每分钟扫描，并在打开归档页时检查一次。只处理已登记、超过保留期且未置顶的空闲会话。运行、交互或命令未完成的会话跳过。取消归档后从恢复时间重新计算保留期，策略和恢复时间原子保存，重启后继续生效。只在应用运行时扫描，关闭后不唤醒系统。

删除必须先在页面确认数量。主进程在任何文件操作前重新核对整批目标必须仍处于归档且没有运行任务。SDK 文件路径不暴露给 Renderer；主进程查证原生身份和目录后送入系统回收站，再移除桌面身份。项目目录和项目文件不删除。部分文件操作失败时保留错误与未完成索引，允许刷新后重试。运行中的归档会话可以取消归档，不能删除。

**链路说明**

```text
[数据与统计] ──┬── 使用统计 ── 只读进程扫描 SDK 历史 ── 日期与模型聚合 ── Canvas 图表
               └── 归档管理 ── 桌面索引与实时宿主 ── 策略或身份校验 ── 原子保存
```

共享 schema 定义在 `src/shared/data-statistics.ts`。主进程组合 IPC 和回收站能力；`WorkspaceService` 管理归档互斥，`WorkspaceStore` 持久化策略与状态。图表使用固定版本 `chart.js@4.5.1`，由 Renderer 构建打包，没有运行时 CDN 请求。

验收入口为 `e2e/settings-data.mjs`。脚本生成独立 SDK JSONL，核对真实 Token、模型、时长、热力图模式、时间范围、搜索筛选、恢复和确认删除、置顶保护、策略重启、分组操作和空状态。测试删除只改名独立 fixture 文件，不触碰用户历史或系统回收站。
