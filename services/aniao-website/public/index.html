BEFORE YOU SET OFF

还有一点小问题？

需要自己接入模型吗？

安装包带有默认模型配置，也支持在设置中添加自己的服务商、模型和 API Key。模型能否使用取决于对应服务的可用状态。

我的文件会保存在哪里？

任务使用你选择的本地项目目录，生成的文件也保存在工作区。使用云端模型时，提交的内容和工具结果会发送给对应模型服务。

AMD 和 Intel 电脑应该下载哪一版？

普通 Intel 和 AMD 的 64 位电脑使用同一架构。Windows 选择 x64 的 .exe，Debian 或 Ubuntu 系 Linux 选择 amd64 的 .deb。ARM 电脑暂不在本次支持范围内。

遇到问题，在哪里反馈？

在应用右上角打开「帮助 → 发送反馈」，可以提交文字和图片。使用或安装时的问题，也可以在 GitHub 仓库中提交 Issue。
